ההזמנה לחתונה של גל וירין
21.02.2027 | קבלת פנים ב־19:30 | הבית, התעשייה 10, רעננה

פתיחה במחשב:
1. חלצו את קובץ ה-ZIP.
2. פתחו את index.html בדפדפן.
3. לחצו על חותם GY לפתיחת ההזמנה ולנגינת המוזיקה.

אם הדפדפן מגביל תוכן מקומי, אפשר להפעיל שרת מקומי מתוך התיקייה:
python -m http.server 8000
ולפתוח בדפדפן: http://localhost:8000

מבנה הפרויקט:
index.html — מבנה ותוכן ההזמנה
style.css — עיצוב והתאמה למסכים
app.js — פתיחת המעטפה, מוזיקה וספירה לאחור
wedding.ics — אירוע ליומן
קובצי WebP — תמונות ועיטורים
A Romantic Flight מופיע בקובץ a-romantic-flight.mp3

אין צורך בהתקנת ספריות או בבנייה. כל קוד האתר והמדיה כלולים.
הגופנים מקומיים ונכללים בתיקיית fonts יחד עם הרישיונות. המפה והקישורים לשירותים חיצוניים דורשים חיבור לאינטרנט.
הקוד ניתן לעריכה בכל עורך טקסט. אפשר לאחסן את תוכן התיקייה בכל שירות לאתרים סטטיים.

לקראת הפרסום בדומיין:
כתובת ההזמנה הקנונית היא https://galandyarin.co.il/ וקישור ההגעה הישיר הוא https://galandyarin.co.il/#details
תמונת השיתוף היא https://galandyarin.co.il/invitation-preview.jpg בגודל 1200×630. כתובות השיתוף מוגדרות ישירות ב-HTML.
לאחר חיבור הדומיין לאחסון, ודאו שהכתובת עם www ושתי כתובות ה-HTTP מפנות לכתובת הקנונית, ושהתעודה תקפה לשני שמות המתחם. בדקו את תצוגת השיתוף ב-WhatsApp באמצעות הכתובת הציבורית.

שני קישורי היומן מציינים את תחילת קבלת הפנים. בקובץ wedding.ics יש שעת התחלה בלבד. בקישור ל-Google Calendar אותה נקודת זמן מופיעה בשני שדות הטווח. לא נקבעה שעת סיום לחתונה.
